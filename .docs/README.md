# 📋 Document Driven Development

## Что это?

Document Driven Development (DDD) — подход к управлению разработкой, при котором вся работа декомпозирована на задачи, описанные в Markdown-файлах. Каждая задача содержит чек-лист, контекст и критерии приёмки.

## Структура

```
.docs/
├── README.md           ← Вы здесь: инструкция по использованию
├── changelog.md        ← Лог завершённых задач и изменений
└── tasks/
    ├── backlog.md      ← Общий бэклог всех задач (сводная таблица)
    ├── template.md     ← Шаблон для создания новой задачи
    └── 001-*.md        ← Индивидуальные файлы задач
```

## Как работать

### 1. Создать новую задачу

```bash
./scripts/tasks.sh create "Описание задачи" [приоритет]
```

Приоритеты: `🔥` (высокий), `🟡` (средний), `💤` (низкий). По умолчанию — 🟡.

### 2. Посмотреть бэклог

Откройте `.docs/tasks/backlog.md` — там сводная таблица всех задач со статусами.

### 3. Показать прогресс

```bash
./scripts/tasks.sh progress
```

### 4. Посмотреть следующую задачу

```bash
./scripts/tasks.sh next
```

### 5. Отметить задачу как завершённую

```bash
./scripts/tasks.sh done 001
```

## Процесс выполнения задачи

1. **Найти задачу** в `backlog.md` со статусом `⬜ Не начато` или `🟡 В работе`
2. **Открыть файл задачи** `.docs/tasks/NNN-название.md`
3. **Выполнить подзадачи** из чек-листа по порядку
4. **Проверить** — запустить `go vet ./...` и `go test ./...`
5. **Зафиксировать** — отметить задачу как ✅ Готово в файле и в backlog.md
6. **Записать в changelog** — добавить запись в `.docs/changelog.md`

## Правила

- Одна задача = один коммит (или связанный набор коммитов)
- Чек-лист должен быть полностью выполнен перед завершением
- Не начинайте задачу, пока не прочитали контекст и критерии приёмки
- Приоритет 🔥 — в первую очередь, 🟡 — между основными задачами, 💤 — когда есть время

## Статусы задач

| Значок | Статус | Описание |
|--------|--------|----------|
| ⬜ | Не начато | Задача в бэклоге, не приступали |
| 🟡 | В работе | Над задачей работают |
| ✅ | Готово | Задача выполнена и проверена |
| 🔴 | Отложено | Временно приостановлена |

## Приоритеты

| Значок | Приоритет | Описание |
|--------|-----------|----------|
| 🔥 | Высокий | Критично, нужно сделать в первую очередь |
| 🟡 | Средний | Важно, но не блокирует работу |
| 💤 | Низкий | Приятно иметь, но можно отложить |
