## Описание

Функция `drawHUD` (game.go:409-441) вызывает `len(g.snake.Body)` без проверки на nil. Если `g.snake == nil`, будет panic. Хотя сейчас `drawHUD` вызывается только из `drawGame`, где есть nil-check, лучше добавить guard для безопасности и инкапсуляции.

## Контекст

- Если в будущем `drawHUD` будут вызывать откуда-то ещё — будет panic
