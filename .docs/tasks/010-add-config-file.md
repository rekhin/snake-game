## Описание

Перенести хардкод констант (CellSize, скорость, очки) в конфигурационный файл YAML/JSON. Это позволит настраивать игру без перекомпиляции.

**Файлы:**
- `game/config.go` — расширить для загрузки из файла
- Новый: `config.yaml` или `snake.json`
