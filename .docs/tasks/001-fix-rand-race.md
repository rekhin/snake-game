## Описание

В проекте используются глобальные функции `rand.Intn()` и `rand.Float32()` из пакета `math/rand` без явного seed. В Go 1.20+ глобальный источник потокобезопасен, но для чистоты кода и предсказуемости в тестах нужно использовать локальные источники `rand.Rand`.

## Контекст

Обнаружено при ревью проекта. Глобальные вызовы `rand.Intn()` в `entity/food.go` и `rand.Float32()` в `game/game.go` могут вызывать проблемы:
- В тестах — непредсказуемое поведение без явного seed
- В рендеринге — потенциальная гонка данных при параллельном вызове

**Файлы:**
- `entity/food.go` — строки 3, 63, 70: импортирует `math/rand`, использует `rand.Intn()`
- `game/game.go` — строки 7, 248-249: импортирует `math/rand`, использует `rand.Float32()`
