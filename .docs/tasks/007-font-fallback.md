## Описание

Если шрифт не загрузится (файл удалён, permissions), игра упадёт с panic. Нужно добавить fallback на системный шрифт или monospace.

**Файлы:**
- `main.go` — инициализация шрифта
- `game/game.go` — использование шрифта
