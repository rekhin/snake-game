# 🐍 Змейка (Snake Game)

Игра "Змейка", написанная на Go с использованием графического движка [Ebitengine](https://ebitengine.purewhite.io/).

## 🚀 Запуск

```bash
# Собрать и запустить
go run .

# Или собрать исполняемый файл
go build -o snake-game.exe .
.\snake-game.exe
```

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| `↑` / `W` | Двигаться вверх |
| `↓` / `S` | Двигаться вниз |
| `←` / `A` | Двигаться влево |
| `→` / `D` | Двигаться вправо |
| `P` / `Esc` | Пауза / Продолжить |
| `Enter` / `Space` | Начать игру / Рестарт |

## 📋 Особенности

- **Классическая механика**: управляйте змейкой, собирайте еду и расти!
- **Нарастающая сложность**: скорость увеличивается каждые 50 очков
- **Счёт и рекорд**: отслеживайте свой лучший результат в течение сессии
- **4 состояния игры**: главное меню, игра, пауза, game over
- **Красивая графика**: тёмная тема, сетка, цветовое кодирование элементов

## 📐 Параметры игры

| Параметр | Значение |
|----------|----------|
| Размер поля | 30 × 25 клеток |
| Размер клетки | 20 пикселей |
| Начальная скорость | 150 мс между ходами |
| Минимальная скорость | 60 мс между ходами |
| Ускорение | Каждые 5 очков (-10 мс) |
| Очки за еду | 10 |
| Начальная длина | 3 сегмента |

## 📋 Документация (Document Driven Development)

Проект использует подход **Document Driven Development** — разработка ведётся через декомпозированные задачи, описанные в markdown-файлах. Это позволяет:

- Разбивать большие задачи на маленькие инкременты
- Чётко отслеживать прогресс по каждому направлению
- Иметь прозрачную историю изменений (changelog)
- Легко онбордить новых участников

### Структура документации

```
.docs/
├── README.md           # Справочник по DDD-процессу
├── changelog.md        # История изменений проекта
└── tasks/
    ├── backlog.md      # Бэклог всех задач (сводная таблица)
    ├── template.md     # Шаблон новой задачи
    └── 001-*.md, 002-*.md ...  # Конкретные задачи
```

### Управление задачами

Используйте скрипт `.docs/scripts/tasks.sh`:

```bash
# Создать новую задачу
.docs/scripts/tasks.sh create "Описание задачи" [приоритет]

# Список всех задач
.docs/scripts/tasks.sh list

# Статус конкретной задачи
.docs/scripts/tasks.sh status 001

# Отметить задачу как завершённую
.docs/scripts/tasks.sh done 001

# Общий прогресс разработки
.docs/scripts/tasks.sh progress

# Показать следующую задачу для выполнения
.docs/scripts/tasks.sh next

# Посмотреть changelog
.docs/scripts/tasks.sh changelog
```

### Статусы задач

| Эмодзи | Статус       | Значение                        |
|--------|--------------|---------------------------------|
| ⬜      | Не начато    | Задача создана, но не начата     |
| 🟡      | В работе     | Активно работаете над задачей    |
| ✅      | Готово       | Задача завершена и проверена     |
| 🔴      | Отложено     | Приостановлена на время          |

### Приоритеты задач

| Эмодзи | Приоритет | Значение                     |
|--------|-----------|------------------------------|
| 🔥     | Высокий   | Критично, делать в первую очередь |
| 🟡     | Средний   | Важно, но не срочно          |
| 💤     | Низкий    | Можно сделать позже          |

### Процесс работы с задачей

1. **Создание**: `.docs/scripts/tasks.sh create "Название" 🔥`
2. **Описание**: Заполните контекст и чек-лист в файле задачи
3. **Начало**: Обновите статус на 🟡 В работе
4. **Выполнение**: Реализуйте, пишите тесты, проверяйте `go vet` и `go test`
5. **Завершение**: Отметьте все пункты чек-листа → `.docs/scripts/tasks.sh done 001`
6. **Changelog**: Запишите изменения в `.docs/changelog.md`
