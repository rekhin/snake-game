# 🐍 Змейка (Snake Game)

Игра "Змейка", написанная на Go с использованием графического движка [Ebitengine](https://ebitengine.purewhite.io/).

## 🚀 Запуск

```bash
# Собрать и запустить
go run .

# Или собрать исполняемый файл
go build -o snake-game.exe .
.\snake-game.exe
```

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| `↑` / `W` | Двигаться вверх |
| `↓` / `S` | Двигаться вниз |
| `←` / `A` | Двигаться влево |
| `→` / `D` | Двигаться вправо |
| `P` / `Esc` | Пауза / Продолжить |
| `Enter` / `Space` | Начать игру / Рестарт |

## 📋 Особенности

- **Классическая механика**: управляйте змейкой, собирайте еду и расти!
- **Нарастающая сложность**: скорость увеличивается каждые 50 очков
- **Счёт и рекорд**: отслеживайте свой лучший результат в течение сессии
- **4 состояния игры**: главное меню, игра, пауза, game over
- **Красивая графика**: тёмная тема, сетка, цветовое кодирование элементов

## 🏗️ Архитектура проекта

```
snake-game/
├── main.go                 # Точка входа, инициализация Ebitengine
├── game/
│   ├── config.go           # Константы: CellSize, скорость, очки
│   ├── state.go            # Состояния игры (Menu, Playing, Paused, GameOver)
│   └── game.go             # Основной игровой цикл, отрисовка
├── entity/
│   ├── direction.go        # Направления движения
│   ├── point.go            # Точка на сетке, размеры поля
│   ├── snake.go            # Логика змейки: движение, рост, столкновения
│   └── food.go             # Еда: спавн в случайной пустой клетке
├── go.mod
└── README.md
```

## 🛠️ Технологии

- **Язык**: Go 1.25+
- **Графика**: [Ebitengine v2](https://github.com/hajimehoshi/ebiten) — 2D game engine
- **Лицензия**: MIT

## 📐 Параметры игры

| Параметр | Значение |
|----------|----------|
| Размер поля | 30 × 25 клеток |
| Размер клетки | 20 пикселей |
| Начальная скорость | 150 мс между ходами |
| Минимальная скорость | 60 мс между ходами |
| Ускорение | Каждые 5 очков (-10 мс) |
| Очки за еду | 10 |
| Начальная длина | 3 сегмента |
